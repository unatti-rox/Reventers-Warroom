# Intake, Project Profile and Brand Profile

## New-project detection

Treat the request as a NEW PROJECT when:
- a new brand, campaign, product, property, film, reel, ad or deliverable begins;
- the user says it's a new project;
- existing context isn't enough to continue safely.

At the start of a new project, don't begin editing. Collect requirements first — but only what hasn't already been supplied in the conversation, uploads, brief, script, brand guidelines, earlier approved instructions for this project, references or production documents.

## Intake checklist (use as applicable — never dump it all on the user)

**Project details** — brand/client · project/campaign name · video type · purpose · campaign objective · target audience · platform · target duration · aspect ratio · resolution · frame rate · language · deadline · number of versions

**Brand details** — guideline file · logo files · approved fonts · brand colours · campaign identity · previously approved videos · tone/personality · visual style · typography behaviour · motion style · CTA style · prohibited treatments

**Source material** — approved footage folder · stills/renders · product/project images · drone · lifestyle · voiceover · interview/dialogue audio · music / approved music library · script · on-screen copy · client-approved frames · reference videos · storyboards · existing edit project / Remotion project / template

**Content & compliance** — approved facts + source documents · CTA · contact details · legal disclaimer · regulatory info · registration/licence numbers · QR source · mandatory shots / messages / end frame · prohibited claims · prohibited visuals · approval owner

**Delivery** — export format · codec · file naming · delivery location · alternate versions · cutdowns · language versions · aspect-ratio versions

## Intake behaviour

Extract first, then ask a short grouped list of what blocks progress. Example:

> Got it — I already have the brand, duration, platform, footage and reference.
> I still need:
> 1. Final CTA
> 2. Logo / brand guidelines
> 3. Voiceover or music direction
> 4. Required disclaimer
> 5. Export resolution

Anything that doesn't block creative development can be marked **TBC** and resolved later. Compliance items (disclaimer, regulatory numbers, CTA, contact details) must be resolved before final export, not before contact sheets.

## Project separation

Never automatically carry over logo, fonts, CTA, disclaimer, legal info, campaign style, pacing, music, typography, facts, contact info, regulatory data or visual treatment from another project. If a previously used brand returns, ask: reuse the existing brand profile, or work from updated guidelines? Project-specific details are always rebuilt.
